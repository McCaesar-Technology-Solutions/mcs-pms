Connect to MOJO

One-time setup. After this, the agent runs in the background from the menu bar / system tray.

  1. On any computer, open MOJO → Owner → Access → Setup
  2. Click Start setup (or Rotate token), then Copy full .env
  3. Paste the fresh block below (old tokens stop working after rotate)
  4. Click Save & start — leave the app in the tray on the apartment PC (same LAN as doors)
